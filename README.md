# Arizona RP Monitor (Yuma + Show Low)

## ВАЖНО — токен
Токен, отправленный в переписку, нужно отозвать через @BotFather (`/revoke`) и получить новый.
Никогда не публикуйте токен и не добавляйте `.env` в Git.

## Установка (Windows)
1. Установите Python 3.11+.
2. Распакуйте архив.
3. В папке проекта выполните:
   `py -m venv .venv`
   `.\.venv\Scriptsctivate`
   `pip install -r requirements.txt`
4. Скопируйте `.env.example` в `.env`.
5. В `.env` вставьте НОВЫЙ токен. ADMIN_ID уже указан.
6. Запуск: `python bot.py`

## Команды
- `/start` — меню
- `/check` — актуальная карточка серверов
- `/admin` — админ-информация (только ADMIN_ID)
- `/ping` — проверка бота
- Кнопки «Подписаться/Отписаться» — уведомления о смене доступности

## Принцип мониторинга
- API: https://online.g-rp.me/api/v1/projects/arizona-rp
- Проверка каждые 20 секунд (можно изменить POLL_SECONDS).
- Изменение `responding` подтверждается двумя последовательными наблюдениями.
- События означают изменение ответа API (`responding`), а не официальное объявление рестарта Arizona RP.
- Если API/сеть временно недоступны, бот не объявляет игровые серверы offline.
- SQLite сохраняет подписчиков между перезапусками.
- Состояние серверов и pending-рестарта сейчас хранится в памяти; после рестарта процесса baseline устанавливается заново.

## Безопасность
- Не добавляйте `.env`, `monitor.db`, токены или логи с секретами в публичные репозитории.
- Бот не исполняет команды из сообщений пользователей и не принимает произвольные URL.
