# Release notes

## v4.5 — Telegram-native control panel

- Rebuilt main screen, navigation and server detail pages.
- Unified period-selectable analytics (Yuma / Vice City / both, 1h / 6h / 24h / 7d).
- Redesigned PNG time-series charts and side-by-side summary report.
- Separate per-server notifications, schedules, thresholds.
- Time-range report selector and on-demand PNG generation.
- Retained current database, status logic, archive and subscriber opt-in.
- Extended runtime tests for Telegram keyboards, message length and chart outputs.
- Added assisted deployment/rollback script for existing Oracle systemd service.
